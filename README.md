# АВТОБЛОГ — Telegram-бот для контента

Бот для SMM автоблога: посты о машинах строго по шаблону канала, комплектация отдельным сообщением,
снижение цены, картинки для сторис, автомонтаж видео с субтитрами, идеи и опросы.

Как установить и пользоваться — см. [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

Ключи и токены хранятся в `.env` (в репозиторий не попадает). Образец — `.env.example`.
